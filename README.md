# kofetch

A small Fastfetch-inspired system information tool written in [Kof](https://github.com/KofLang/Kof4j).

It displays basic system information with colored ASCII logos and platform-specific detection.

## Supported platforms

- macOS
- Linux
  - Fedora
  - Arch Linux
  - Ubuntu
  - Debian
- Windows — implemented, pending real-world validation

Tested with Kof `0.4.0-beta`.

## Run

```bash
kof run src/main.kf
```

## Tested on

- macOS arm64 — Apple M2
- Fedora Linux x86_64
